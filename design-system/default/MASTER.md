# 一桌好戏 · 界面约定

面向聚会中传阅一部手机的中文桌游。采用暖纸底色、深绿文字、珊瑚与麦黄纸牌插画。自动搜索给出的深色、3D 和定价页方向不适合当前任务，此处以实际游戏流程覆盖这些建议。

- 背景 #f7f3e8；卡纸 #fffcf5；正文 #263d31；按钮 #2d614b；次要文字 #6d7468；珊瑚 #ed987b；麦黄 #edcc77。
- 使用系统中西文字体，无运行时字体下载。中文标题加粗，少量英文短标签提供层次，所有操作和规则完整中文表达。
- 圆角纸卡、细描边、轻微错位的牌面；插画由 CSS 和内联 SVG 构成，图标不使用 emoji。私密卡保持一致布局。
- 页面：游戏大厅、设置、读卡交接、私密卡、公共发言、投票交接、秘密投票、揭晓、最终排名。
- 主要按钮至少 54px 高，其他操作至少 44px；可见焦点；勾选状态通过图形和颜色表达；支持 reduced-motion。
- 320px 至 430px 手机优先，桌面设置页双栏。阅读解释 16–17px，允许长解释与滚动；知情人与瞎掰人使用同一私密卡布局和倒计时。
- 手机布局、触控可用性和动态隐私行为尚待浏览器验收；不能把设计值当成实测结果。
