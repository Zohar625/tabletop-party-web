# 数字房间码、自由揭菜与盖碗动画

用户要求：房间码更好输入；允许直接揭别人的菜；上菜有合盖、揭菜有开盖动作。

实现计划：
- 新房间使用六位纯数字，保留旧版八位邀请与恢复；新建房间先探测占用，检测到已有房主时提示重建；已建立的房间不会被其他房主广播关闭。
- 挑战者自由选择任意非空叠菜，始终从顶端揭；其他结算、丢菜、两次成功获胜保持现有逻辑。界面和教学明确为自由揭菜变体。
- 在已确认的上菜/揭菜后播放动画，恢复页面不重播旧动作；公开合盖动画不包含暗牌内容，支持减少动态效果。
- 验证：引擎边界、房间码兼容和冲突、动画状态及牌面保密、全量测试、三个真实网络客户端、构建与部署。

验证结果：
- Node 82 项通过；Python 11 项通过。
- TypeScript、三个入口构建、本地打包及资源检查通过。
- 三个真实 WebSocket 客户端：数字码加入、同时初放、自己放坏菜后直接揭对手好菜得分、成员及房主恢复均通过。
- 独立代码审查通过；补充旧页面探测后写入前的进度保护。
- 公开中转上的占用探测属于尽力检测，不提供中心服务器的原子房号分配；完整邀请链接仍固定房主身份。

状态：准备发布并验证手机界面。
