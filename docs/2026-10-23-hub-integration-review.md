# 双游戏大厅与存档修复验收

## 本次范围

- 一桌好戏大厅新增超级井字棋入口，独立页面隔离样式与运行状态。迁移来源为旧项目 `42de619`，保留原版全盘三连规则、本地双人、三套皮肤、悔棋、重开确认、互动教学。
- 合并版本不包含 MQTT 联机模块；旧项目和旧网址保持原样。
- 两款游戏分别构建。新增棋盘不会增加瞎掰王入口的 React/棋盘资源。井字棋页面可返回大厅，进行中的棋局先询问确认。
- 离线包生成两个同目录 HTML，每个游戏的脚本与样式都内联，导航使用本地文件名。

## 一并完成的稳定性修复

- 只在阅读阶段运行 100 毫秒倒计时，避免其他阶段反复重渲染；题池与历史计算使用缓存。
- 去掉反复压入相同网址的浏览器历史操作。
- 私密阅读时禁用规则、退出、重发按钮，切后台时收卡并关闭遮挡弹窗。弹窗增加可访问名称。
- 存档恢复检查剩余整局容量、发言与投票阶段一致性；异常题池无法生成缺卡的下一轮。
- 保存前检查当前存档是否仍匹配该页面的最后一次写入，避免旧页面倒退其他页面的进度；历史更新合并最新记录。
- 独立审查发现退出动作绕过过时检查，现将两个清除入口统一交给 `session.discard()`，过时退出被拒绝。新增回归测试已观察失败后修复通过。

多页面保护是同步存储的快照核对，不是跨标签页原子事务锁；不声称解决完全同时写入的所有竞争条件。
