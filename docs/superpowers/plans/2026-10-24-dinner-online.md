# 这口能吃吗实施计划

**目标：** 用户已批准：3–6 人房间联机，原版 Skull 基础规则，料理换肤、刷新重连、互动教程，接入现有大厅。

**架构：** 独立 Vite 页面。纯状态机负责规则与公开/本人投影；房主主持状态，成员通过加密消息提交操作、接收各自投影。沿用旧井字棋的 EMQX WebSocket MQTT 中转方式，但不广播完整游戏状态。ECDH P-256 + AES-GCM 点对点加密，身份私钥与房主存档仅存本机。公共中转仅用于朋友间试玩，不承诺商用服务保障或恶意房主防作弊。

**技术：** React 19 / TypeScript 6 / Vite 8 / Web Crypto，无新增依赖。

## 规则范围

依据发行商基础规则（2023规则册，不启用“最后机会”变体）。每人3正常1黑暗，赢两轮或最后存活获胜。每轮先各放一张，首家最后放；此后首家开始顺时针加菜或开价。竞价只能提高或退出，退出后本轮不可再入。挑战先翻本人，再翻其他人各叠顶牌；达到目标即赢。踩到自己黑暗牌秘密自选丢牌，踩他人黑暗牌随机丢牌，仅本人获知。挑战者继续做首家；若被他人淘汰，该黑暗牌主人做首家；自我淘汰时本人指定首家。

官方规则：https://cdn.svc.asmodee.net/production-spacecowboys/uploads/2025/12/SKULL_RULES_FR.pdf

## 连接和信任边界

房间使用高熵随机代码避免碰撞。成员持久化 ECDH 身份，房主保留成员公钥；重连不以昵称认领身份。加入时固定房主公钥，分享链接携带房主指纹，拒绝换主。每条操作带唯一 ID 与状态版本，房主串行验证；周期快照纠正丢包，过期快照忽略。暂停等待离线参与者，不替玩家自动出牌。房主不自动迁移，存储不可用时明确提示无法刷新恢复。

公共中转无法提供可用性 SLA，也不能抵御主动阻断、房主修改客户端或首次手输代码时的恶意冒充。联机试玩不声称具备独立服务器裁判保障。之后可替换中转与房间主持器，不改变规则状态机。
