# SCOUT Turn Clock Implementation Plan

**Goal:** 房主可设每段时限，先提醒重计再自动合法行动，本人手牌区就地高亮。
**Architecture:** 独立turn-clock模型生成时钟和合法兜底动作；ScoutRoom持久化、串行超时、版本同步；TurnTimer显示校准倒计时，ScoutTable控制本人容器高亮。
**Tech Stack:** React / TypeScript / CSS，现有加密MQTT、现有引擎，无新增依赖。

- [ ] 模型测试：不计方向/结算；每次合法动作新时钟；兜底动作在2–5人完整对局合法、不重排、不用连演。
- [ ] 房间回归：主机权限与输入验证、第一段不改游戏版本、第二段只行动一次、刷新不重计、聊天/心跳不重计、关闭限时、旧快照不能倒退阶段、旧记录恢复。
- [ ] 实现房间设置、时钟广播/校准/持久化与超时串行处理，保留原请求权限和冲突检查。
- [ ] UI回归与实现：底板/框高亮而不改卡面、固定操作区两段倒计时、临近动画及减少动态效果、房主设置。
- [ ] 全量测试、独立审查、手机浏览器实测、构建、发布及线上资源核验，记录真实网络限制。
