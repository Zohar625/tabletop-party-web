# 制图师网页体验设计草案

日期：2026-10-25
状态：用户已于本会话确认方案，进入实现与验证。

## 目标

在一桌好戏中增加制图师游戏入口，兼顾单人和朋友联机。用户从未玩过，教程与手机操作必须优先于扩展内容；界面要有完整地图绘制的成就感。

## 方案比较

1. 推荐：基础规则、原创手绘视觉、完整交互教学，单人与联机共用规则引擎。学习一次便可切换模式。
2. 先做纯单人：更早交付，但朋友加入还需要等待联机实现。
3. 自创简化规则：容易入门，但会偏离用户选定的制图师。本次不采用。

## 首版范围

- 基础 A 面地图与基础版探索、伏击、四季和16种计分目标；暂不加入地图扩展与英雄内容。
- 单人：随时开局、本机自动保存、恢复、历史成绩。使用单人伏击规则和目标基准扣分后的评级，区别原始总分与评级。
- 联机：2–6人，六位数字房间码和邀请链接。全桌共用探索牌及目标，各自同时绘图，全部确认后推进。伏击时按牌指定方向切换到邻座地图，由邻座绘制怪物后归还，不能用单人自动怪物替代。
- 承接现有公共中转方案：房主保存权威状态、校验操作；设备恢复身份；断线提示并暂停推进，不引入付费后台。沿用完整邀请链接的房主身份固定方式。
- 成绩由规则计算，不由客户端提交任意分数。每个玩家的形状、地形、旋转镜像、位置和回合号必须由引擎验证。

## 教学

默认入口突出“先学会玩”，允许直接开始或重看。

采用独立固定教学地图与牌序，教程不写正式战绩，也不影响联机房间。每一步只解释一个概念，并要求真实操作完成后才继续：

1. 看探索牌：选择地形与形状。
2. 旋转或镜像：地图中显示半透明合法预览。
3. 点击位置、确认落笔：展示不可重叠与不可越界。
4. 围住山峰获得金币：用高亮与数字反馈说明原因。
5. 根据一个目标布置地形，点击目标展示计分区域。
6. 学习遗迹限制与无法放置时的替代格。
7. 体验怪物及相邻空格扣分，解释单人与多人伏击差异。
8. 完成一次季末计分：逐项高亮目标、金币和怪物影响，随后进入正式游戏。

教学允许上一步、重试、退出；错误放置给出位置与原因，不能只弹“操作无效”。规则帮助保留简短例图和完整中文说明。

## 视觉与手机交互

原创羊皮纸、墨绿与铜金色调；地图使用清晰的手绘地形：森林、红顶村落、麦田、水纹、山峰和怪物。缩小后仍有轮廓和纹理差异，不能只依赖颜色。

桌面布局为中央地图、侧边探索牌与目标栏；手机布局地图优先，下方固定操作区。11×11地图支持放大和平移，提供明确位置预览；以点击预览加确认作为主要方式，拖拽只作辅助，避免手指遮挡时误放。正式提交前可取消预览，提交后不能回退窥看下一张牌。

目标栏明确当前季节生效的两项目标。点击目标高亮对应得分区域；季节时间、金币和等待队友状态必须一眼可见。联机不显示大弹窗遮住地图等待其他人。

## 动画

- 探索牌翻开，形状预览跟随选择变化。
- 地形落笔分格短促显现，森林与房屋有轻微生长感；水纹保持克制。
- 围山金币反馈，伏击有预警与地图交接提示。
- 季末逐项展示分数来源，四季以边框色和光感变化，地图始终易读。
- 动画不能阻塞必要操作；重连不重播旧回合。遵循减少动态效果偏好。
- 最终地图保留完整展示，支持分享地图图片，不公开昵称或其他个人信息，除非玩家选择包含。

## 技术划分

独立 cartographers 入口与样式，接入现有大厅。纯规则引擎负责棋盘合法性、牌序、季节推进、计分与单人伏击；会话层负责本机持久化和联机命令；地图组件仅展示状态及预览；教程使用同一套放置与计分方法，避免教会的操作与正式局不同。

美术以可缩放原创 SVG 为主，背景纹理可按需要补充；不直接复用官方插画或原文教程。

## 验证与完成条件

- 对照官方规则建立边界案例：镜像旋转、山峰、遗迹接伏击、无合法形状、满图、相邻空格去重扣分、目标连通与季节累计、单人评级。
- 自动测试覆盖核心规则和恢复；模拟及真实多客户端覆盖同步放置、伏击交接、断线恢复和重复命令。
- 构建所有既有入口，确认不影响其他桌游。
- 手机与桌面验证教程完整路径及地图操作；浏览器工具若不可用，应明确记录未完成的视觉验证，不能声称已经实测。
- 发布仍使用现有 GitHub Pages，不变更现有托管平台。
