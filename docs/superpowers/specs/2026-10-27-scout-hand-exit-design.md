# SCOUT 房客退出、房间号与手牌整理

前置的回合高亮/聊天已经发布并核验。按用户要求接着执行以下明确反馈。

1. 房客在任何阶段都可以通过二次确认“放弃本局并退出”，包括房主永久离线。该操作不依赖房主回执，结束本地连接并按身份校验删除本机座位；说明无法恢复该座位，本局可能需要其他人重新开桌。旧页面不能删除更新的房间身份。
2. 创建/加入共用清晰标注的六位房间号，创建可以留空随机，指定时必须使用原号码；加入必填。保留已有碰撞检测，号码占用明确报错，不自动换号。
3. 大数字为当前朝向，小数字为另一朝向，旋转180度时互换。去掉加减装饰线，仅6和9保留下划线。
4. 增加“叠牌概览/展开操作”切换，手机默认叠牌，电脑默认展开。叠牌最多每行6张、错位露出每张牌左上大/小数字；不改变实际手牌顺序。需要选牌时可展开，插牌自动使用原展开布局，取消后恢复概览偏好。
5. 三至五人头像旁显示原创巡演票标记，金色正面可用、深色背面已用；用状态切换翻面动画，带文字提示和减少动态效果支持。双人不显示该标记。

验证：房主断线后的客人退出/刷新/新开桌，旧控制器保护新身份；指定号码及碰撞；卡面朝向与6/9；手机12张叠牌无横向滚动、切换与原选牌插牌流程；标记翻面及他人可见；全量测试、独立审查和浏览器实测后发布。
