# 一桌好戏

手机优先的聚会桌游网页。大厅可以选择「瞎掰王·冷知识局」、「超级井字棋·田园双人局」、联机试玩「这口能吃吗」以及单人/联机「制图师」。瞎掰王每个人抽到不同的词，只有一位瞎掰人看不到真实解释。

试玩地址：https://zohar625.github.io/tabletop-party-web/ （由 GitHub Actions 部署）。瞎掰王保持单手机传阅；超级井字棋保持同屏双人；「这口能吃吗」支持3–6人各自手机联机。

## 制图师 · 四季绘图

入口：https://zohar625.github.io/tabletop-party-web/cartographers/index.html

原创羊皮纸和手绘地形界面，基础 A 面地图，支持单人远征与 2–6 人联机。首次可进入八步实操教学：选择地形、旋转镜像、落笔确认、围山金币、目标高亮、遗迹与替代格、邻座怪物、季末计分。地图支持放大和平移；正式提交前可以移动或取消预览。单人进度自动保存在当前浏览器，并记录结局评级；完局后可导出不含昵称的地图 PNG。

首版实现基础版13张探索牌（含两张遗迹）、4张伏击牌和16项目标，地图坐标与规则参考出版方说明，形状、方向及单人基准逐张对照授权 Yucata 牌图。四季累计声望；单人结局额外扣除目标基准，多人平分依四季怪物总扣分较少者获胜，仍同分共同获胜。不是官方授权客户端，未使用官方插画或原文教学。

联机共用探索和目标，各自同时提交；伏击时实际切换到邻座地图绘制怪物。未来牌序只保留在房主状态，客户端收到加密公开投影；联机房间沿用现有公共 MQTT 中转、六位码和完整身份固定邀请链接，房主需保持在线，断线时保留座位等待恢复。页面加载完成后单人可离线进行，首次打开页面及联机需网络；本地大厅入口会打开线上制图师页面。

验证脚本：`node --experimental-strip-types scripts/verify-cartographers-online.ts`。它使用三个真实 WebSocket 客户端验证数字码入室、同时落笔、牌序隐藏和刷新恢复。自动化另覆盖四季完整对局、单人伏击扫描、全部计分边界及八步教程。当前没有可用浏览器自动化接口，尚未完成真实手机上的视觉、触控和 PNG 下载验收，不将构建或 SSR 视作手机实测。

## 这口能吃吗 · 联机试玩

入口：https://zohar625.github.io/tabletop-party-web/dinner/index.html

创建房间后分享完整邀请链接，朋友输入昵称加入并准备，由房主开桌。6位数字房间码也可手输（兼容旧版8位码）；完整链接同时固定房主身份，建议优先分享链接。基于 Skull 基础规则，采用“自由揭菜”变体：挑战者可直接揭任意玩家最上面的一道菜，无需先揭自己的菜。原创料理界面，不启用最后机会变体；每人三道正常菜和一道黑暗料理，菜单共有32道正常菜、8道黑暗料理，每局随机搭配。菜式不附加技能。内置可操作教学。

客户端通过 EMQX 公共 MQTT WebSocket 中转，房主主持规则和保存整局状态。成员仅接收公开桌面及自己的手牌投影，ECDH P-256 / AES-GCM 分别加密，未翻牌和丢牌身份不会广播。房主和成员身份保存在各自设备；支持同设备、同浏览器来源刷新恢复。退出进行中的对局会暂停连接并保留恢复入口，不自动代替玩家出牌。房主需要保持页面打开，离线时等待重连，不自动迁移房主。

这是朋友间联机试玩，不是带独立服务器裁判的竞技服务。公共中转可能故障或被网络屏蔽；不承诺恶意房主防作弊、首次手输代码时的身份抗冒充、跨设备恢复或服务 SLA。不会要求付费服务器；不向中转发送真实姓名或账号凭证。菜名、昵称与中转连接可能产生服务元数据，试玩时使用昵称即可。

本地大厅中的联机入口会打开在线页面；网络不可用时不能用离线HTML联机。其余两款游戏的本地打包方式保持。

独立网络验收（不进入常规测试/CI，不安装依赖）：

```powershell
node --experimental-strip-types scripts/verify-dinner-online.ts
```

该命令用三个实际 WebSocket 客户端创建临时测试桌，验证加密同步、完整一轮和刷新恢复。它不等于手机浏览器交互验收。

当前已合入270道离谱真事长卡，保留原90题，默认读卡5秒、默认4人。全新词池足够9人连续三整局不重复。旧5包共450题原样保留为归档，不混回新题池。浏览器审批服务曾返回403，手机视觉、实际点击、后台事件与刷新行为尚未完成浏览器实测，不应据此宣称已完成手机验收。用户已授权发布 GitHub 网页试玩版。

超级井字棋位于 `super-tic-tac-toe/index.html`，提供同屏双人、悔棋、重开确认、三套皮肤和互动教程。合并版本不提供联机。旧网址 https://zohar625.github.io/super-tic-tac-toe/ 保持不变，旧仓库未改动。棋局仅在当前页面保留，刷新或离开会结束棋局；返回大厅按钮在未结束棋局时会先确认。

## 本地试玩

项目根目录的 `一桌好戏-本地试玩.html` 包含大厅、瞎掰王、样式和题库；`超级井字棋-本地试玩.html` 包含独立的双人棋盘。两个文件放在同一目录，可从大厅进入井字棋并返回，各游戏本身不依赖外部资源。不需要安装 Node 或下载依赖。该文件形式尚待实际浏览器验收；当前浏览器工具的安全策略禁止打开 file 协议。浏览器若限制文件页存储，页面会提示无法保存；建议使用下述本机服务器以获得稳定的存档来源。

开发服务器：

```powershell
cd 'D:\西安电子科技大学\闲来没事干点活\tabletop-party-web'
npm run dev
```

打开命令输出的本机地址。手机访问电脑的 localhost 会指向手机自己；手机试玩请使用上方 GitHub Pages 地址。

重新构建两个本地试玩文件（自动校验脚本语法、资源及跳转）：

```powershell

```

依赖安装在项目的 D 盘目录，npm 缓存位于 `D:\App\npm-cache`。

## 玩法

1. 规则支持3–9人，每人使用座位号。9人一圈需要81题，默认4人。默认读卡5秒，也可选10、20、30秒或自定义5–120秒。历史排除后若题量不足，仍会阻止开局并提示。
2. 每人拿到不同的词。交接页显示下一位编号和词名，点击才开始读卡。知情人得到真实解释；唯一瞎掰人只得到词名与编造任务。
3. 到时卡片锁定，阅读中切后台、关闭或刷新会结束此次阅读。当前解释约129–189个汉字，不要求读完，知情人用记住的真实信息讲解，允许遗漏与停顿。保留一部分名称直白的题，不要求所有词都生僻难懂。
4. 全员读完后公开词名，依次发言。每轮的首位发言人按座位轮换，之后自由讨论。
5. 逐人秘密投票，不能投自己，确认后不能修改。所有人提交后统一揭晓。瞎掰人也投票，但其票不计分或有效票数。
6. 知情人投中得 1 分；瞎掰人每骗过一位知情人得 1 分。每轮新增总分恒为 N−1。共 N 轮，每轮从所有玩家中独立随机抽取一名瞎掰人，允许连续重复，不保证每人都当过。同分并列。

遇到熟词或误读，可以确认整轮重发；作废轮不加分，换新词并独立重抽本轮瞎掰人。题量不足以完成剩余整局时阻止重发。旧存档恢复后保留当前已发身份，下一轮起按新规则独立抽取，已有分数与历史不变。

## 题包和历史

- 当前题包：真事比瞎编离谱，270题。原90题完整保留，本轮共新增180题：自然70、器物与历史70、习俗赛事与科学40，使用186个实际阅读的不同来源页面。逐题来源与核实边界见 `data/editorial/180-card-expansion-review.md`；原90题记录见 `data/editorial/long-card-expansion-review.md`。尚待实际聚会评估5秒阅读压力和身份平衡。
- 当前登记来自 `data/playtest-registry.json`，Vite 自动载入 `data/playtest/*.json`。新增或扩充可玩题包后更新此登记并重新构建，无需修改游戏流程。
- 原有奇妙动植物、古代器物与生活、世界民俗、自然与科学现象、中国古代职业各90题，保留在 `data/packs/` 和 `data/pack-registry.json`，作为旧题库归档。不会混入当前新局。
- 同概念按 `conceptId` 去重。一局内不重复；跨局默认排除本设备已展示词。历史仅在词名被展示时记入，不提前把整局预分配题记作已见。
- N 人一圈需要 N² 道可用题。不足时需要增加题包或主动允许使用历史题。清空历史需要确认。
- 允许历史只放宽跨局限制，不增加本局容量。若恢复旧存档，原题池、时长、身份和积分保持原样；新题只在重新开桌后进入题池，不静默改变进行中的对局。
- 项目专用维护技能位于 `.agents/skills/tabletop-theme-packs/SKILL.md`，没有安装全局技能。

## 代码边界

- `src/games/bluff/engine.ts`：纯规则、带种子发牌、事件序号校验、阶段与结算、公开/个人视图。
- `src/games/bluff/questions.ts`：题包加载；原始题目及核实证据仍保留在 `data/`。
- `src/session/types.ts`：界面只依赖 `SessionAdapter`，通过 `getPublicView`、`getPrivateView`、`dispatch`、`subscribe` 访问会话。
- `src/session/localSession.ts`：本机存档、结构校验、恢复消耗读卡、历史记录、保存失败提示。
- `src/App.tsx`：大厅、设置、传阅、发言、投票、揭晓与排名。无房间服务、账号或假联机按钮。

未来联机需由服务端保存完整状态，发牌、校验、计分；客户端只收到公开视图和本人的个人卡片，不能下发全部秘密再用样式隐藏。本地版用于朋友正常传阅，不能防开发者工具或冒领下一位身份；本地文件和网址来源的历史也不会自动互通。
